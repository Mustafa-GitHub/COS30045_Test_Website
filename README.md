# WattWise: Appliance Energy Consumption

WattWise is a small educational website for COS30045. It demonstrates HTML, CSS and JavaScript through a three-page appliance energy consumption guide for the Australian market.

## Pages

- **Home**: An introduction to energy labels, appliance habits and consumption.
- **Televisions**: Illustrative television energy profiles and an interactive yearly-use estimator.
- **About Us**: Project context, scope and Australian-market disclaimer.

The pages are rendered from one HTML shell. JavaScript uses the URL hash (`#home`, `#televisions`, and `#about`) to swap views, update the active navigation state and maintain direct links to each page.

## Run locally

Open `index.html` in a browser. No build tools or dependencies are required.
